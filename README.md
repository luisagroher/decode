**We spend 10x more time reading code than writing it. So why are we trained only to write code?**

This is a practice group for developers who want to get better at the skill of reading code.

There are a variety of resources for people who want to learn code: resources that guide us through projects, resources for learning data structures and algorithms, and resources for learning frameworks. All of these resources are focused on learning to write code but there are few resources dedicated to teaching people how to read code even though we spend more time reading than writing code.

And with AI is handling an increasing amount of code generation, humans will need even more to develop the skill for reviewing, understanding, and integrating code rather than writing it from scratch.

This pilot group will:

- practice reading unfamiliar code
- develop and share strategies for code comprehension
- build comfort jumping into messy, real-world code
- learn from each other's approaches
- build muscle for reading code quickly in any language


**Let's train for the skill that we actually need.**
